# Arquitetura do Acutis

## Contexto

O frontend Nuxt oferece a interface e uma BFF com chamadas explícitas. O backend NestJS administra projetos locais e coordena Git, filesystem, SQLite, Playwright e provedores de IA. O pacote `contracts` define os dados compartilhados nas fronteiras.

## Contêineres

```text
Pessoa
  ↓
Frontend Nuxt
  ↓ valida contracts
Backend NestJS
  ├── filesystem de projetos
  ├── Git
  ├── SQLite de configurações
  ├── Playwright
  └── provedores de IA
```

## Componentes do backend

```text
src/controllers/<domínio>
  ↓
src/use-cases/<domínio>
  ↓
src/modules/<domínio>/*.service.ts
  ↓
ports e providers
  ↓
filesystem, Git, SQLite, Playwright e IA
```

Os arquivos `*.module.ts` registram controllers, casos de uso, services e adaptadores no contêiner do Nest. Controllers não importam services ou providers diretamente.

## Fronteiras executáveis

Os testes em `backend/src/architecture` verificam a localização das camadas, contratos compartilhados, dependências proibidas, acesso centralizado à configuração e ausência de proxy genérico no Nuxt.
