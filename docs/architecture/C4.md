# Arquitetura do Acutis

## Contexto

O Nuxt entrega a interface e o Nitro executa a API, o gravador, o runner e o WebSocket no mesmo processo. Os contratos Zod ficam em `shared/contracts` e são consumidos pela interface, pelos handlers e pelo núcleo.

## Contêiner

```text
Pessoa
  ↓
Nuxt + Nitro
  ├── interface Vue
  ├── handlers HTTP e WebSocket
  ├── contratos Zod
  └── composição explícita
       ↓
     core
       ├── casos de uso e serviços
       ├── filesystem e Git
       ├── SQLite
       ├── Playwright
       └── provedores de IA
```

## Componentes

```text
server/api e server/routes
  ↓
server/utils/composition
  ↓
core/use-cases e core/modules
  ↓
ports e providers
  ↓
filesystem, Git, SQLite, Playwright e IA
```

O Nitro valida entradas e respostas com os schemas compartilhados. A composição cria as dependências explicitamente, sem contêiner de injeção. Os testes em `core/architecture` verificam as fronteiras, a ausência dos artefatos Nest e a localização dos contratos.
